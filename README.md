# Micromouse

<p align="center"> <a href="https://madheshiyaraj562-cmyk.github.io/Micromouse/"> <strong>🌐 Visit the Website To Get The Data </strong> </a> </p>


*A beginner-friendly research project on building and understanding Micromouse robots.*

**🌐 Live Simulators:**
[MicroMouse Simulator](https://madheshiyaraj562-cmyk.github.io/Micromouse/simulation_for_MicroMouse_map.html) · [Flood-Fill Simulator](https://madheshiyaraj562-cmyk.github.io/Micromouse/floodfill_simulation.html)

A beginner's guide to building a Micromouse robot — covering batteries, motors, motor drivers, encoders, PID control, sensors, algorithms (Flood Fill, A*, DFS/BFS), mechanical design, PCB design, and testing/calibration.

> 🚧 **Status:** The research paper is updated :D.

---

## Contents

| File | Description |
|---|---|
| `MicroMouse_Research_paper.pdf` | The full write-up (80 pages) — rules, history, hardware (motors, batteries, voltage regulators, motor drivers, encoders), PID control theory and tuning, sensors (IR, ToF, IMU), Flood Fill / A* / DFS algorithms, mechanical design, and PCB design. |
| `floodfill_simulation.html` | An interactive game where you drive a mouse through a maze yourself, then reveal how the Flood Fill algorithm would have solved it, with an efficiency score. |
| `simulation_for_MicroMouse_map.html` | An autonomous A* + PID simulator — the mouse plans a path with A* and drives it with a tunable PID heading controller, replanning live if you draw new walls. |

## What's Inside the Research Paper

- Micromouse competition rules & history
- Batteries (Lead-Acid, NiMH, LiPo) and voltage regulation
- Motors (Brushed DC, BLDC) and the N20 gear motor
- Motor drivers, H-Bridges, and the TB6612FNG dual H-Bridge IC
- Wheel encoders and distance/speed calculations
- PID control theory, tuning, and common problems (overshoot, oscillation, integral windup)
- Sensors: Infrared (IR), Time-of-Flight (ToF), IMU
- Maze-solving algorithms: Flood Fill, Weighted Flood Fill, DFS, BFS, A*
- Mechanical design: chassis, wheels, center of gravity, caster vs. skid
- PCB design workflow
- Testing, calibration, and debugging
